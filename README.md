# 温暖旅途 - 移动端民宿预订 Web 应用

## 项目概览

本项目是独立设计开发的 C 端民宿预订单页应用（SPA），对标主流民宿平台移动端交互体验，完整覆盖房源浏览、条件搜索、详情查看、用户收藏、地图找房等核心预订业务链路。

从需求拆解、技术选型、功能开发、性能优化到线上部署全流程独立完成，重点打磨长列表性能、搜索交互、跨域兼容、地图数据联动等前端高频业务场景，项目已完成多轮功能迭代，目前稳定上线运行。

## 技术栈

- **前端框架**：Vue 3（Composition API） + Vue Router + Pinia
- **构建工具**：Vite
- **开发语言**：JavaScript (ES6+)
- **样式方案**：Scss
- **网络请求**：Axios（统一封装拦截器）
- **地图服务**：高德地图 JS API
- **包管理工具**：pnpm
- **部署方案**：Vercel 自动化部署 / Cloudflare Workers，绑定自定义域名

## 核心功能

- 房源首页与分类列表展示，支持无限滚动分页加载
- 多维度房源筛选与关键词搜索，含搜索历史记录与结果高亮
- 房源详情页完整信息展示，包含评分、配套、图片轮播等交互
- 用户收藏功能，基于 Pinia + localStorage 实现状态持久化
- 地图找房模式，房源点位与列表数据双向联动
- 入住时间、入住人数等预订参数全局状态管理

## 核心技术亮点

### 1. 全局状态管理与数据持久化

使用 Pinia 管理用户地址、入住时间、收藏数据等全局状态，结合 localStorage 实现数据持久化，保证页面刷新后用户操作状态不丢失；拆分状态模块，保证状态流转清晰可维护。

### 2. 长列表无限滚动性能优化

基于 IntersectionObserver 实现房源列表无限滚动加载，设计请求锁机制与数据结束标识，从根源避免重复请求、漏请求问题；对滚动逻辑做防抖处理，降低高频触发性能损耗；搭配骨架屏与加载状态提示，优化弱网下用户感知。
实现数百条房源数据滚动流畅无卡顿，同时将无效请求量降低 60% 以上。

### 3. 工业级实时搜索交互

封装防抖函数控制搜索请求触发频率，解决用户连续输入时接口频繁调用问题；基于 localStorage 实现本地搜索历史记录，覆盖空结果、加载中、异常报错的全状态交互；新增关键词匹配高亮，提升搜索体验。

### 4. 通用业务组件封装

抽取 HouseShow、Favor、Rating 等多类通用业务组件，覆盖核心页面 80% 以上复用场景，减少重复代码，提升功能迭代效率，同时保证交互与视觉一致性。

### 5. 统一网络请求层封装

基于 Axios 封装请求库，通过请求/响应拦截器统一管理 Loading 状态、错误提示与重复请求取消，降低接口层代码冗余，统一异常处理逻辑。

### 6. 地图服务集成与时序处理

接入高德地图 SDK，完成地图初始化、自定义点位标记、坐标与房源数据的联动渲染；解决地图异步加载与接口数据返回的时序不一致问题，保证列表与地图点位一一对应、同步更新；对多点位渲染做批量挂载优化，避免频繁触发地图重绘。

### 7. 多环境跨域解决方案

开发环境基于 Vite 反向代理实现接口转发，规避浏览器同源策略限制；深入梳理 CORS、Nginx 反向代理、JSONP 等跨域方案的实现原理与适用场景，明确生产环境跨域落地方案，具备多环境部署问题解决能力。

### 8. 移动端全机型适配

采用 rem + 视口适配方案，覆盖主流手机屏幕尺寸，保证不同设备下布局一致性与交互可用性；处理移动端点击延迟、滚动回弹、输入框唤起等常见兼容问题。

## 性能优化实践

1. **路由懒加载**：对非首页路由做代码分包，拆分业务代码模块，首屏加载体积减少约 35%
2. **图片懒加载**：结合原生 `loading="lazy"` 与占位图方案，首屏图片请求量减少约 50%
3. **请求优化**：统一拦截器实现请求取消、错误统一处理、重复请求过滤
4. **打包优化**：配置 Vite 构建压缩，剔除无用依赖，优化生产产物体积
5. **交互优化**：搜索防抖、滚动防抖，减少无效计算与接口请求，提升响应速度
